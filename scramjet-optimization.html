Project 01

Multifidelity Scramjet Optimization using ML

Overview

This project explored the use of multifidelity computational fluid dynamics data for theoretical scramjet optimization. The goal was to combine lower-cost and higher-fidelity simulation data into a more efficient optimization workflow.

The work used hyperkriging and machine learning methods to model complex relationships across CFD datasets. The project was shown as a proof of concept while working at the Air Force Research Laboratory's High Speed Systems Division.

Technical Focus

The project involved CFD data handling, surrogate modeling, optimization, and analysis of high-speed flow behavior. Python was used for data processing and model development, with CFD outputs serving as the basis for the learning workflow.

Additional plot or result

Results and Takeaways

This work demonstrated how multifidelity modeling can reduce the computational burden of scramjet optimization while preserving useful design-space information from higher-fidelity simulations.
